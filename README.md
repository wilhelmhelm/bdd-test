# Проверка знаний по БДД — ITECO

Статический сайт: открывается двойным щелчком по `index.html` или работает на GitHub Pages. Сервер не нужен.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страниц (старт, тест, настройки, реестр, протокол) |
| `style.css` | оформление и печатная форма протокола |
| `app.js` | вся логика, адрес реестра `REG_URL`, ключ `REG_KEY` |
| `data.js` | билеты и вопросы (по одному вопросу на строку), список рисунков |
| `img/` | рисунки к вопросам (`i1.jpg` … `i62.jpg`), логотип, фон, иконки |
| `config.js` | (ваш существующий файл, в архив не входит) пресет колонн и комиссии; если его нет, страница работает без него |

## Как править вопрос
Откройте `data.js`, найдите вопрос поиском (Ctrl+F) и поправьте строку `"t"` (текст), `"o"` (варианты) или `"a"` (номер верного варианта: 0 = а, 1 = б, 2 = в…). Строка начинается с `{"t":`.

## Как заменить рисунок
Положите новый файл в `img/` под тем же именем (например `i12.jpg`).

## Как залить на GitHub
1. Откройте репозиторий → **Add file → Upload files**.
2. Перетащите **содержимое** папки (файлы и папку `img`), не саму папку `bdd-site`.
3. Подтвердите: **Commit changes**. Через 1–2 минуты GitHub Pages обновится.
4. Если файл `config.js` уже есть в репозитории, не удаляйте его.

## Сброс кэша браузера
В `index.html` у `style.css`, `data.js` и `app.js` стоит `?v=11`. После каждого обновления увеличивайте число (`?v=12`…), и браузеры сразу подхватят новые файлы.
