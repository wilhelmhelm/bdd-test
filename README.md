# Проверка знаний по БДД — ITECO

Статический сайт: открывается двойным щелчком по `index.html` или работает на GitHub Pages. Сервер не нужен.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страниц (старт, тест, настройки, реестр, протокол) |
| `style.css` | оформление и печатная форма протокола |
| `app.js` | вся логика, адрес реестра `REG_URL`, ключ `REG_KEY` |
| `data.js` | билеты и вопросы (по одному вопросу на строку), список рисунков |
| `img/` | рисунки к вопросам (`i1.jpg` … `i62.jpg`), логотип, фон, иконки |
| `comissions.js` | составы комиссий по колоннам (правится вручную, см. ниже) |
| `config.js` | необязательный, старый способ; если есть `comissions.js`, он главнее |

## Состав комиссии для разных колонн
- **Файл `comissions.js`** лежит рядом с `index.html`. Формат: `33: [["ФИО", "Должность"], ...]`, до 5 человек. Ключ: номер колонны (`33`) или `"общий"` (для колонн без своего состава). Пример есть в самом файле.
- **Как создать без ручного набора:** задайте составы в странице («✎ Изменить состав для этой колонны» или «Настройки»), затем «Настройки» → «Текст для comissions.js», скопируйте текст и вставьте в файл `comissions.js` в репозитории (Add file → Create new file, либо Edit у существующего).
- Состав из файла главнее сохранённого в браузере для тех колонн, которые в нём указаны. Для остальных колонн работает состав, сохранённый в браузере, и общий.
- После правки файла увеличьте число `?v=…` у `comissions.js` в `index.html`, иначе браузеры какое-то время покажут старый состав.
- Ссылка для водителя короткая, если состав колонны взят из `comissions.js`, иначе длинная (состав вписан в ссылку).
- Файл публичный, как и вся страница: только ФИО и должности.

## Как править вопрос
Откройте `data.js`, найдите вопрос поиском (Ctrl+F) и поправьте строку `"t"` (текст), `"o"` (варианты) или `"a"` (номер верного варианта: 0 = а, 1 = б, 2 = в…). Строка начинается с `{"t":`.

## Как заменить рисунок
Положите новый файл в `img/` под тем же именем (например `i12.jpg`).

## Как залить на GitHub
1. Откройте репозиторий → **Add file → Upload files**.
2. Перетащите **содержимое** папки (файлы и папку `img`), не саму папку `bdd-site`.
3. Подтвердите: **Commit changes**. Через 1–2 минуты GitHub Pages обновится.
4. Если файл `config.js` уже есть в репозитории, не удаляйте его.

## Сброс кэша браузера
В `index.html` у `style.css`, `data.js` и `app.js` стоит `?v=13`. После каждого обновления увеличивайте число (`?v=13`…), и браузеры сразу подхватят новые файлы.
