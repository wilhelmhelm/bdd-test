# Проверка знаний по БДД — ITECO

Статический сайт: открывается двойным щелчком по `index.html` или работает на GitHub Pages. Сервер не нужен.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страниц (старт, тест, настройки, реестр, протокол) |
| `style.css` | оформление и печатная форма протокола |
| `app.js` | вся логика, адрес реестра `REG_URL`, ключ `REG_KEY` |
| `data.js` | билеты и вопросы (по одному вопросу на строку), список рисунков |
| `img/` | рисунки к вопросам (`i1.jpg` … `i62.jpg`), логотип, фон, иконки |
| `comissions.js` | составы комиссий (единственный источник, см. ниже) |
| `config.js` | необязательный, старый способ; если есть `comissions.js`, он главнее |

## Состав комиссий: только через comissions.js
Сотрудники **не могут** менять комиссии на странице: кнопки «Настройки» и «Изменить состав» скрыты, а всё, что раньше было сохранено в браузерах, игнорируется. Единственный источник составов — файл `comissions.js` в репозитории.

**Как изменить состав**
1. GitHub → репозиторий → файл `comissions.js` → значок карандаша (Edit).
2. Правьте записи. Формат: `33: [["Фамилия Имя Отчество", "Должность"], ["...", "..."]],` — номер колонны, затем до 5 человек. Запись `"общий": [...]` подставляется колоннам без своего состава.
3. **Запятая** нужна после каждого человека и после каждой колонны (кроме последней). Кавычки только прямые `"`.
4. Commit changes. Через 1–2 минуты откройте страницу, выберите колонну и проверьте состав.
5. Если важно, чтобы новый состав появился сразу у всех: в `index.html` увеличьте число у `comissions.js?v=…` (например, с 14 до 15).

**Если страница показывает красное сообщение**: «Не удалось прочитать comissions.js» — в файле синтаксическая ошибка (скобка, запятая, кавычка) или файла нет; «ошибка в записи состава» — между людьми пропущена запятая.

**Кто может менять:** только люди с правом записи в репозиторий. В истории коммитов GitHub видно, кто и когда менял состав.

**Вернуть ручное редактирование** (на время): в `app.js` строку `var COMM_LOCKED = true;` заменить на `false`.

## Как править вопрос
Откройте `data.js`, найдите вопрос поиском (Ctrl+F) и поправьте строку `"t"` (текст), `"o"` (варианты) или `"a"` (номер верного варианта: 0 = а, 1 = б, 2 = в…). Строка начинается с `{"t":`.

## Как заменить рисунок
Положите новый файл в `img/` под тем же именем (например `i12.jpg`).

## Как залить на GitHub
1. Откройте репозиторий → **Add file → Upload files**.
2. Перетащите **содержимое** папки (файлы и папку `img`), не саму папку `bdd-site`.
3. Подтвердите: **Commit changes**. Через 1–2 минуты GitHub Pages обновится.
4. Если файл `config.js` уже есть в репозитории, не удаляйте его.

## Сброс кэша браузера
В `index.html` у `style.css`, `data.js` и `app.js` стоит `?v=14`. После каждого обновления увеличивайте число (`?v=14`…), и браузеры сразу подхватят новые файлы.
